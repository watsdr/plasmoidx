# Outside links and mentions plan for plasmoidx.com

Status: plan only, written 2026-10-15. Nothing here has been posted, sent, or submitted.
Every item needs Derek's go-ahead before anyone acts on it.

## Ground rules

- Honest, useful, disclosed. Say who runs Plasmoid X (independent education, sells no kits, not a licensee).
- One relevant link per post or message. Link the page that answers the question, not the home page.
- Lead with the measured result, then label claims and criticism. That is the site's selling point.
- Never ask friends to upvote, never use second accounts, never buy or swap links.
- Never tag or contact private individuals who did not ask for it (for example the thesis author, a student).
- Accept "no" and removal requests without argument. Do not let anyone dictate the Measured / Inventor claim / Outside commentary labels.
- Rules for outside sites change. Where this plan says "check the rules", read the live rules before acting. Reddit blocked our fetch tool, so no subreddit rule here was verified.

> Plasmoid X is an independent, plain-English explainer site about Malcolm Bendall's Thunderstorm Generator. It sells no kits.

- Paid links, link swaps, "SEO directories", guest-post farms, and comment spam. They carry penalty risk and clash with the site's honesty brand.
